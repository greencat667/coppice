# This folder

This is a [Coppice](https://github.com/greencat667/coppice) workspace: plain files that give an AI assistant persistent context about you and your work.

- **`START-HERE.md`** — the session protocol the assistant follows. You rarely need to edit it.
- **`soul.md`** — about you. You own it.
- **`setup.md`** — your tools, contexts and budgets. No secrets.
- **`TASKS*.md`** — what's live now, one file per context.
- **`memory/`** — projects index, recent sessions, learning log, glossary, people.
- **`projects/`** — one folder per project.
- **`context/`** — reference material, including Coppice's own docs in `context/coppice/`.

To start a session, open this folder in your assistant and say something like *"Read START HERE and let's go."*
