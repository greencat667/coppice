# Setup

> The machine side of this workspace: contexts, tools, where things live, and the budgets that keep the startup read small. The assistant reads this every session, so keep it short.
>
> **Never put a secret in this file** — no passwords, API keys or tokens. List each credential by *name* and say where it's kept (e.g. the OS keychain, or a `.env` file that is never committed or shared). The assistant will ask for access when it needs it.

---

## Contexts

A context is a mode of work with its own tasks and recent-sessions files. Most people need one or two. The assistant picks today's context from the **When** column. If none match, or a request crosses contexts, it reads all of them.

| Context | When | Tasks file | Recent sessions |
|---|---|---|---|
| main | always | `TASKS.md` | `memory/recent.md` |

*Example with two contexts:*

| Context | When | Tasks file | Recent sessions |
|---|---|---|---|
| work | Mon–Wed | `TASKS-work.md` | `memory/recent-work.md` |
| personal | Thu–Sun | `TASKS-personal.md` | `memory/recent-personal.md` |

## Folders

| Folder | Holds |
|---|---|
| `projects/` | One folder per project: `NNN-short-name/` (lower-case, hyphens, no spaces; rule 27) with `index.md`, `log.md`, `brief/`, `inputs/`, `working/`, `outputs/` |
| `memory/` | Projects index, recent sessions, archive, learning log, glossary, people, heartbeat |
| `context/` | Reference material the assistant reads on demand |
| `reports/` | Files generated by scheduled tasks (kept for the number of days set in the budgets below) |
| `working/` | Temporary inbox; emptied at the end of each session |

## Budgets

Limits that keep the startup read fast and the files useful. `coppice doctor` checks these and reports anything over. Change the numbers to suit you; keep the block format.

```yaml
budgets:
  startup_tokens: 8000        # START-HERE.md + soul.md + setup.md + one context's tasks and recent files
  tasks_kb: 15                # per tasks file
  recent_days: 21             # older recent-session entries move to memory/archive/YYYY-MM.md
  learning_log_kb: 12         # active entries only; graduated and discarded ones are archived
  reports_days: 60            # generated reports older than this are deleted by archive-trim
  stale_flag_days: 5          # a briefing flag repeated this many days must escalate
project_roots:                # folders holding numbered project folders; list several to number them separately
  - projects
ignore:                       # paths the doctor skips entirely; uncomment and edit to use
  # - "*/saved-pages/*"
secrets_accepted:             # files where you've knowingly left a credential for now; reported as one note, not errors
  # - "context/old-setup-notes.md"
root_allowed:                 # the only files allowed in the workspace root
  - START-HERE.md
  - AGENTS.md
  - CLAUDE.md
  - soul.md
  - setup.md
  - TASKS*.md
  - README.md
```
